# Traveler - Frontend сайта для бронирования отелей

Репозиторий содержит HTML-страницы и CSS-стили для многостраничного сайта по поиску и бронированию отелей "Путешественник".

## 🛠 Технологии

- **HTML5** — семантическая верстка
- **CSS3**:
  - CSS-переменные для цветовой схемы
  - Flexbox для адаптивных layout'ов
  - Grid для сложных сеток
  - Адаптивная верстка на основе медиа-запросов
- **БЭМ-методология** (классы вида `block__element`)

## ✨ Функциональность

### 🏠 Главная страница (`index.html`)
- Слайдер с Топ-10 отелей России
- Быстрый поиск по названию отеля (datalist)
- Блок преимуществ сервиса
- Сетка популярных отелей
- Форма подписки на новости
- Расширенная форма поиска отелей

### 🔍 Поиск (`search.html`)
- Расширенная форма поиска с фильтрацией
- Боковая панель с фильтрами:
  - Ценовой диапазон
  - Тип размещения (отель, апартаменты, хостел)
  - Удобства (Wi-Fi, парковка, бассейн и др.)
  - Количество звезд
  - Рейтинг по отзывам
  - Тип питания
  - Расположение от центра
- Переключение между отображением списком/на карте
- Пагинация результатов

### 🏨 Карточка отеля (`result.html`)
- Детальная информация об отеле
- Фотогалерея
- Контактные данные
- Описание и особенности
- Рейтинг и категория

### 👤 Личный кабинет (`profile.html`)
- Просмотр личной информации
- Разделение бронирований на:
  - ✅ Подтвержденные
  - ⏳ Ожидающие подтверждения
- Редактирование данных профиля
- Управление бронированиями

### 🏢 Партнерский раздел

#### Добавление отеля (`add.html`)
- Форма с обязательными полями:
  - Контактный телефон
  - E-mail отеля
  - Юридические данные
  - Количество звезд
  - Расположение
- Загрузка фотографий (до 3 шт.)
- Выбор удобств
- Установка пароля для управления

#### Управление бронированиями (`orders-management.html`)
- Фильтрация заявок по статусу
- Карточки бронирований с разными статусами:
  - 🟠 На модерации
  - ✅ Подтверждено
  - ❌ Не подтверждено
- Возможность подтверждения/отклонения заявок

### 🔐 Авторизация
- **Вход** (`login.html`) — форма с валидацией email/пароля
- **Регистрация** (`register.html`) — форма с валидацией:
  - Проверка совпадения паролей
  - Валидация телефона (формат +7)
  - Минимальная длина пароля
  - Согласие на обработку данных

## 💻 Установка и запуск

1. **Клонируй репозиторий**
   ```bash
   git clone https://github.com/mirazhgit/traveler.git
   ```

2. **Перейди в папку проекта**
   ```bash
   cd traveler
   ```

3. **Открой в браузере**
   - Просто открой `index.html` в любом современном браузере
   - Или используй Live Server в VS Code для автоматической перезагрузки
